  from 'https://your-app.rennko.tech/__/init.js'

await app.auth.signInWithGitHub()
const chat = app.db.collection('messages')

// Live: runs now from the offline cache,

  render(snap.docs.map(d => d.data())))

</script>

Everything a Firebase app needs

The same ideas you already know, with no install, no build step and no setup beyond picking a name.

👤

Auth

Email and password, anonymous, GitHub and Google sign-in. Anonymous users can upgrade later and keep their data.

⚡

Realtime database

Collections and documents with queries. onSnapshot listeners update the moment anything changes.

📴

Works offline

Data is cached on the device. Writes show up instantly, wait in a queue that survives reloads, and sync when you're back online.

🗂️

File storage

Upload images and files and get shareable links. Rules decide who can read and write.

🌐

Hosting

Drag your site's folder into the console, or run rennko deploy. Only changed files upload.

🛡️

Security rules

Simple rules like doc.owner == auth.uid keep each user's data theirs.

Offline-first, not offline-maybe

Rennko Cloud apps keep working on a plane, in a tunnel or on bad Wi-Fi. You don't write any extra code.

Write anywhere

set() and add() update your UI right away, connected or not.

Saved on the device

Pending writes and cached data live in IndexedDB, so a reload or a crash loses nothing.

Synced when online

Writes reach the server exactly once, and every listener gets the latest data.

Free, for real

Rennko Cloud runs on Cloudflare's free tier, which is fast, global and always on, even while your computer is off. It's also open source: run your own copy on your own free Cloudflare account with one command.
